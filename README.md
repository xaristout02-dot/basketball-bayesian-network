
# Basketball Game Outcome Prediction — Bayesian Network

A Simple Bayesian Network model for predicting basketball game outcomes, built with **GeNIe Academic**.

## Network Structure

| Node | Description |
|------|-------------|
| PlayerForm | Form of the player (High/Medium/Low) |
| OpponentStrength | Strength of opponent (Strong/Medium/Weak) |
| TeamFatigue | Team fatigue level (High/Low) |
| HomeAway | Home or away game |
| OffensePerformance | Offensive performance (High/Medium/Low) |
| DefensePerformance | Defensive performance (High/Medium/Low) |
| PsychologicalAdvantage | Psychological edge (Positive/Neutral/Negative) |
| TeamOverallPerformance | Overall team performance (Excellent/Good/Poor) |
| MatchResult | Final result (Win/Loss) |

## How to Open

Open the `.xdsl` file with [GeNIe](https://www.bayesfusion.com/genie/) (free academic version available).
